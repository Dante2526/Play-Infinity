🕵️‍♂️ Testador de API de Streaming

Cole a URL de qualquer API de filmes (ex: https://superflixapi.cyou/filme/299534) para testar como ela reage quando tentamos bloquear os pop-ups.

Player SEM Bloqueio Com Pop-ups

Iframe padrão. Se rodar o filme, mas abrir pop-ups quando você clica, significa que a API está funcionando mas os anúncios estão embutidos.

Player COM Bloqueio Sem Pop-ups

Iframe com sandbox="allow-scripts allow-same-origin". Se a tela ficar preta, rodando infinitamente ou der erro, a API tem detecção anti-sandbox avançada.
